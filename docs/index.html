Architectural Comparison

Project Zomboid Optimiser (PZO)
Dynamic Non-Invasive Engine (Safe)
  • Zero Disk Overrides: PZO uses a dynamic JVMTI JavaAgent and native C library (`PZPathFind64.dll`). Vanilla game `.class` files are never overwritten on disk.
  • Patch-Resilient: When The Indie Stone updates Build 42 (e.g. 42.21 → 42.22 → 42.23), PZO's dynamic hooks adapt automatically without corrupting game mechanics.
  • Proprietary Native A* Engine: Features high-performance indexed decrease-key C acceleration inside Project Zomboid's pathfinding thread for massive swarm performance.
  • Slick Modern Control Center: 7 organized categories in F10 with full user control, live diagnostics, and zero hardcoded silent overrides.
PZ_Optimization (pzopt)
Whole-Class Source Overrides (Brittle)
  • 140+ Vanilla Classes Overwritten: Decompiles vanilla game classes and places modified `.class` files directly into the game folder.
  • Fragile Across Patches: Every minor game update breaks or corrupts game state, vehicle mechanics, and recipes because old bytecode overwrites new game code.
  • Roadmap Cloned from PZO: Features were systematically added 8 to 36 days after PZO published the discoveries and engineering blueprints.
  • Silent Background Alterations: Forces hundreds of silent toggles without a transparent, user-friendly control interface.

The Corroborating Evidence: pzopt's Internal Registry

The definitive proof of prior art is not external speculation. Inside pzopt's own client distribution, the file media/lua/client/pzopt/pzopt_optimizations_dates.lua contains 1,375 lines documenting the exact calendar date every toggle was added.

Cross-referencing this internal file confirms that not a single one of the 7 core performance breakthroughs existed in pzopt prior to September 19, 2026—weeks after PZO had already proven and published them.
